Image Tuner 개인정보처리방침

시행일: 2026년 11월 2일

Image Tuner는 웹 페이지의 이미지와 동영상을 그 자리에서 보정하고, 보정한 이미지를 파일로 저장하는 Chrome 확장 프로그램입니다. 이 확장 프로그램은 개발자나 제3자의 서버로 사용자 데이터를 보내지 않습니다. 광고와 사용 통계도 넣지 않았습니다.

다루는 데이터와 쓰는 이유

  • 웹사이트의 이미지: 히스토그램, 자동 보정, 저장에 원본 픽셀이 필요합니다. 사용자가 보정 창을 연 이미지를 그 이미지의 원래 주소에서 다시 받아 브라우저 안에서만 계산합니다.
  • 쿠키: 로그인해야 보이는 이미지도 받을 수 있도록, 이미지를 다시 받을 때 브라우저가 그 이미지의 사이트 쿠키를 함께 보냅니다. 확장 프로그램은 쿠키를 읽거나 저장하지 않습니다.
  • 마우스와 키 입력: 마우스 아래에 이미지가 있는지 확인해 버튼을 띄우고, 보정 창의 단축키를 처리하는 데에만 씁니다. 기록하지 않습니다.
  • 사이트 이름: 사용자가 "이 사이트에서 항상 적용"을 켠 사이트의 호스트 이름과 보정 값, 버튼을 끌어 옮긴 사이트의 호스트 이름과 버튼 자리를 저장합니다. 방문 기록은 저장하지 않습니다.
  • 사용자가 만든 설정: 프리셋, 복사한 보정 값, 불러온 LUT의 색 표와 이름(최근 8개), 색 맞추기 기준 이미지의 색 분포 숫자와 파일 이름, 보정 창의 탭과 분석 화면 선택을 저장합니다.

저장 위치

위의 설정은 이 브라우저의 확장 프로그램 저장 공간에만 저장합니다. 버튼 표시 켜기/끄기 값 하나만 Chrome 동기화 저장 공간을 쓰므로, Chrome 동기화를 켠 경우 그 값이 사용자의 Google 계정을 통해 다른 기기로 전달됩니다.

제3자 제공

사용자 데이터를 판매하거나 제3자에게 넘기지 않습니다. 이미지 요청은 그 이미지가 있는 원래 사이트로만 갑니다.

Limited Use 준수

Image Tuner의 사용자 데이터 사용은 Chrome 웹 스토어 사용자 데이터 정책의 Limited Use 요구 사항을 따릅니다. 데이터는 이미지 보정과 저장이라는 단일 목적에만 쓰며, 광고, 신용 평가, 사람이 읽는 용도로 쓰지 않습니다.

보관과 삭제

저장한 값은 사용자가 지우거나 확장 프로그램을 제거할 때까지 남습니다. 자동 적용 사이트는 툴바 팝업에서, 프리셋과 LUT는 보정 창에서 지울 수 있고, 버튼 자리는 버튼을 더블클릭하면 지워집니다. 확장 프로그램을 제거하면 모두 지워집니다.

변경

데이터를 다루는 방식이 바뀌면 이 문서와 시행일을 고칩니다.

Image Tuner Privacy Policy

Effective: November 2, 2026

Image Tuner is a Chrome extension that adjusts images and videos in place on web pages and saves adjusted images as files. It does not send user data to the developer or to any third-party server, and it contains no ads or analytics.

Data handled and why

  • Images on websites: The histogram, auto adjust and save need the original pixels. When you open the adjustment panel on an image, the extension downloads that image again from its original address and processes it only inside your browser.
  • Cookies: So that images behind a login can be loaded, the browser sends that site's cookies with the image request. The extension does not read or store cookies.
  • Mouse and keyboard input: Used only to detect an image under the pointer, show the button, and handle panel shortcuts. Input is not logged.
  • Site names: The host name and adjustment values of sites where you turn on "always apply on this site", and the host name and button position of sites where you drag the button. Browsing history is not stored.
  • Your settings: Presets, copied values, color tables and names of imported LUTs (latest 8), color statistics and file name of a color-match reference image, and the selected panel tab and scope.

Where data is stored

The settings above are stored only in this browser's extension storage. The single on/off value for showing the button uses Chrome sync storage, so if Chrome sync is on, that value travels through your Google account to your other devices.

Sharing

User data is not sold or transferred to third parties. Image requests go only to the site that hosts the image.

Limited Use

Image Tuner's use of user data adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only for the single purpose of adjusting and saving images, and not for advertising, creditworthiness, or human reading.

Retention and deletion

Stored values remain until you delete them or remove the extension. Auto-apply sites can be removed in the toolbar popup, presets and LUTs in the panel, and a button position by double-clicking the button. Removing the extension deletes everything.

Changes

If data practices change, this page and its effective date will be updated.
